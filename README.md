# file_ingest_key_analyser (WIP) - Very early beta use only for developers

**File Ingest Key Analyser** — is a system designed to **analyze and extract key data from documents and structured files**.  
It provides a modular pipeline for **detection, parsing, and metadata extraction**, suitable for embedding in larger systems or using as a standalone tool.

## Features

- **Modular pipeline:** separate stages for detection, parsing, and extraction  
- **File type detection:** magic bytes, headers, and heuristics  
- **Metadata extraction:** text, author, title, timestamps, and custom fields  
- **Safe execution:** clean shutdown and isolated processing
